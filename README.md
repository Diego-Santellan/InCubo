# InCubo

Sitio web de InCubo con React y Vite. El frontend funciona de forma independiente.

## Desarrollo local

Instala las dependencias y arranca Vite desde la raíz del proyecto:

```bash
npm install
npm run dev
```

Abre la URL que muestre Vite, normalmente `http://localhost:5173`.

Las obras se guardan en `data/constructions.json` y las imágenes subidas en `uploads/`. Los usuarios del acceso general se mantienen localmente en el navegador.

## Comandos

```bash
npm run build
npm run lint
npm run typecheck
```
